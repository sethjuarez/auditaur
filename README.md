# auditaur

Runtime observability for Tauri apps and AI agents.

Auditaur is a local-first development toolkit for inspecting Tauri app logs, traces, frontend errors, IPC calls, events, and window state through a CLI and MCP server.

It is also intended to act as a local OpenTelemetry sink for app and third-party library telemetry, preserving generic spans and logs alongside Tauri-specific records.

The public docs site is planned for [auditaur.dev](https://auditaur.dev).

See [docs/reference/IMPLEMENTATION_PLAN.md](docs/reference/IMPLEMENTATION_PLAN.md) for the detailed implementation plan.
