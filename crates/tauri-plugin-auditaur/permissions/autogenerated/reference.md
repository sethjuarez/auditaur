## Default Permission

Allow the Auditaur frontend SDK to export telemetry batches.

#### This default permission set includes the following:

- `allow-export-otel-batch`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`auditaur:allow-export-otel-batch`

</td>
<td>

Enables the export_otel_batch command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`auditaur:deny-export-otel-batch`

</td>
<td>

</td>
</tr>
</table>
