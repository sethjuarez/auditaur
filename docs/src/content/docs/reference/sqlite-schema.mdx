---
title: SQLite Schema
description: Initial Auditaur SQLite schema overview.
---

The initial schema is OpenTelemetry-aligned and optimized for local debugging queries.

Core tables:

```text
sessions
resources
logs
spans
span_events
span_links
frontend_errors
tauri_ipc_calls
tauri_events
tauri_windows
metrics
screenshots
```

`logs`, `spans`, and `frontend_errors` are implemented and queryable through the CLI and MCP server. The Tauri-specific tables are present in the schema so future IPC, event, window, metric, and screenshot records can be added without a disruptive migration.

JSON attributes are stored as text. The store enables WAL mode, uses a busy timeout for multi-connection reads, and validates schema version `1` in `doctor --db`.
