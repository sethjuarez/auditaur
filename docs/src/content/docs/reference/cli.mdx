---
title: CLI Reference
description: Auditaur CLI commands for inspecting SQLite sessions.
---

Read commands discover the active Auditaur session automatically when `--db` is omitted. Pass `--db <path>` to select a specific SQLite database.

```text
cargo run -p auditaur-cli -- doctor [--db <path>]
cargo run -p auditaur-cli -- doctor tauri [--path <app-or-src-tauri-path>] [--json]
cargo run -p auditaur-cli -- apps [--json]
cargo run -p auditaur-cli -- health [--json]
cargo run -p auditaur-cli -- sessions [--db <path>] [--json] [--limit <n>]
cargo run -p auditaur-cli -- logs [--db <path>] [--json] [--session <id>] [--trace <id>] [--since <duration>] [--limit <n>]
cargo run -p auditaur-cli -- errors [--db <path>] [--json] [--session <id>] [--trace <id>] [--since <duration>] [--limit <n>]
cargo run -p auditaur-cli -- exceptions [--db <path>] [--json] [--markdown] [--output <path>] [--fingerprint <id>] [--session <id>] [--trace <id>] [--since <duration>] [--limit <n>]
cargo run -p auditaur-cli -- traces [--db <path>] [--json] [--session <id>] [--since <duration>] [--failed] [--limit <n>]
cargo run -p auditaur-cli -- trace <trace-id> [--db <path>] [--json] [--session <id>]
cargo run -p auditaur-cli -- ipc [--db <path>] [--json] [--session <id>] [--trace <id>] [--since <duration>] [--failed] [--limit <n>]
cargo run -p auditaur-cli -- events [--db <path>] [--json] [--session <id>] [--trace <id>] [--since <duration>] [--limit <n>]
cargo run -p auditaur-cli -- windows [--db <path>] [--json] [--session <id>] [--limit <n>]
cargo run -p auditaur-cli -- timeline [--db <path>] [--json] [--session <id>] [--trace <id>] [--since <duration>] [--limit <n>]
cargo run -p auditaur-cli -- related [--db <path>] [--json] [--session <id>] [--trace <id>] [--window <label>] [--since <duration>] [--limit <n>]
cargo run -p auditaur-cli -- explain [--db <path>] [--json] [--session <id>] [--trace <id>] [--since <duration>] [--limit <n>]
cargo run -p auditaur-cli -- bundle [--db <path>] [--session <id>] [--trace <id>] [--since <duration>] [--redacted] [--output <path>] [--limit <n>]
cargo run -p auditaur-cli -- tail [--db <path>] [--session <id>] [--trace <id>] [--replay] [--interval-ms <ms>] [--duration-seconds <n>] [--json]
cargo run -p auditaur-cli -- mcp
```

Human output is compact and bounds table cells. JSON output uses camelCase fields matching the Rust model.

`--since` accepts durations such as `30s`, `10m`, `2h`, or `1d`. `timeline` merges logs, spans, frontend errors, IPC calls, events, and window states into one chronological view. `related` returns the correlated structured rows behind trace, window, session, and recent-activity investigations. `explain` summarizes obvious failures. `exceptions` groups captured frontend exceptions, Rust panic-hook records, and failed IPC calls by stable fingerprint. Use `--fingerprint <id>` to drill into one group, `--markdown` for a GitHub issue-ready draft, and `--output <path>` to write the JSON or Markdown report to disk; review and redact the local report before posting it publicly. `bundle` always redacts share-sensitive JSON fields and exports bounded JSON suitable for bug reports or handoffs; `--redacted` is accepted for explicitness.

`apps` reads discovery files from the local Auditaur data directory and marks entries stale when the heartbeat is older than 30 seconds. Stale entries for the same app identity are annotated with `supersededBySessionId`, `secondsUntilNextStart`, and `churnHint` when a newer session appears after them. This helps distinguish a normal app exit from likely restart/session churn, such as a Tauri dev watcher rebuild after source edits. `health` summarizes active/stale app health from heartbeat freshness, session churn hints, database readability/schema validation, and collector capability version skew; stale apps are surfaced but do not fail the overall report. Staleness is heartbeat-only today; platform-specific PID existence checks are not implemented yet. `doctor --db` validates a specific SQLite database; `doctor` without `--db` validates discovery files and readable database paths. `doctor tauri` checks a Tauri app for the Auditaur crate, plugin registration, and required capability permission.
