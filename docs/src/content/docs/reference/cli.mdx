---
title: CLI Reference
description: Auditaur CLI commands for inspecting SQLite sessions.
---

Read commands discover the active Auditaur session automatically when `--db` is omitted. Pass `--db <path>` to select a specific SQLite database.

```text
cargo run -p auditaur-cli -- doctor [--db <path>]
cargo run -p auditaur-cli -- apps [--json]
cargo run -p auditaur-cli -- sessions [--db <path>] [--json] [--limit <n>]
cargo run -p auditaur-cli -- logs [--db <path>] [--json] [--session <id>] [--trace <id>] [--limit <n>]
cargo run -p auditaur-cli -- errors [--db <path>] [--json] [--session <id>] [--trace <id>] [--limit <n>]
cargo run -p auditaur-cli -- traces [--db <path>] [--json] [--session <id>] [--limit <n>]
cargo run -p auditaur-cli -- trace <trace-id> [--db <path>] [--json] [--session <id>]
cargo run -p auditaur-cli -- ipc [--db <path>] [--json] [--session <id>] [--trace <id>] [--limit <n>]
cargo run -p auditaur-cli -- events [--db <path>] [--json] [--session <id>] [--trace <id>] [--limit <n>]
cargo run -p auditaur-cli -- windows [--db <path>] [--json] [--session <id>] [--limit <n>]
cargo run -p auditaur-cli -- mcp
```

Human output is compact and bounds table cells. JSON output uses camelCase fields matching the Rust model.

`apps` reads discovery files from the local Auditaur data directory and marks entries stale when the heartbeat is older than 30 seconds. Staleness is heartbeat-only today; platform-specific PID existence checks are not implemented yet. `doctor --db` validates a specific SQLite database; `doctor` without `--db` validates discovery files and readable database paths.
