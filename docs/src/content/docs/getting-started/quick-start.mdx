---
title: Quick Start
description: The target development loop for using Auditaur with a Tauri app.
---

The target quick start is:

1. Add `tauri-plugin-auditaur` to the Tauri app.
2. Initialize `@auditaur/api` in the frontend.
3. Run the app in development mode.
4. Inspect the local session with `auditaur logs`, `auditaur errors`, `auditaur traces`, or `auditaur mcp`.

Auditaur should be enabled automatically only for debug builds or when explicitly requested with `AUDITAUR=1`.
