---
title: Installation
description: Planned installation paths for Auditaur.
---

Auditaur is not published yet. The MVP will provide:

1. A Rust CLI binary named `auditaur`.
2. A Tauri v2 plugin crate named `tauri-plugin-auditaur`.
3. A frontend package named `@auditaur/api`.

Until the first release, build from source in the repository.
