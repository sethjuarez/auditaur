---
title: Roadmap
description: Auditaur implementation milestones.
---

Auditaur will be built in phases:

1. Repository scaffolding and docs.
2. SQLite session store.
3. CLI read path.
4. Tauri plugin embedded collector.
5. Expand the OpenTelemetry JS sink beyond spans to logs, metrics, and automatic instrumentation setup.
6. Frontend API package.
7. Rust tracing integration.
8. MCP server.
9. Example Tauri app and dogfood loop.
10. Public docs polish.
11. OTLP/sidecar receiver for telemetry produced outside the Tauri plugin path.
